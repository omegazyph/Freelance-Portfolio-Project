This is the Standard Tier tool which performs dual-action:
1. Data Extraction: Saves invoice details to a CSV report.
2. File Organization: Automatically renames your PDF files 
   to a standardized format (Date_Amount.pdf).

🚀 HOW TO USE:
1. Place your PDF files inside the 'Invoices' folder.
2. Double-click 'run_standard_tool.bat'.
3. The script will rename the files in place and generate 
   a 'Report.csv' in the 'Output' folder.

🛠 REQUIREMENTS:
- Python 3.x
- Libraries: pdfplumber, pandas
- (Run 'pip install -r requirements.txt' if needed)

NOTE:
If a file name already exists (e.g., two invoices with the 
same date and amount), the script will skip renaming that 
specific file to prevent data loss.
