# The omegazyph Intake Form

    1. Environment: 
        Will this script run on Windows 11, macOS, or a Linux server? 
    
    2. Samples: 
        Can you provide 3–5 sample PDFs? (I need these to calibrate the extraction logic for different layouts). 
        
    3. Output Preference: 
        Do you prefer the data in CSV, Excel, or a live Google Sheet? 
        
    4. Frequency: 
        Is this a one-time cleanup, or do you need a tool you can run daily? 
        
    5. Special Rules: Are there specific files or keywords the script should ignore?
