# 📑 Invoice Data Extractor (Advanced Enterprise)

Author: omegazyph | Updated: 2026-02-11

## 💎 Advanced Tier Exclusive

* **Live Google Sheets Sync:** Automatically uploads data to your cloud spreadsheet.
* **No Manual Uploads:** Your accounting team sees the data as soon as you run the script.
* **Full Automation:** Includes the file organizer and the one-click launcher.

## 🛠 Setup

1. Place your `credentials.json` in the root folder.
2. Ensure your Google Sheet is named "Invoice_Data_Sync" and shared with the client_email in your JSON file.
3. Run `run_tool.bat`.
