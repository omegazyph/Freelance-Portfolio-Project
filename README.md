# Portfolio of Automation and System Utilities

## Overview

This repository serves as a centralized collection of professional automation tools and system scripts developed by omegazyph. The projects contained herein focus on system administration, log analysis, and data preservation, utilizing a combination of Bash shell scripting and Python.

## Primary Hardware and Environment

All scripts within this repository have been developed and tested on the following environment to ensure maximum stability and performance:

* **System**: Lenovo Legion Laptop
* **Operating System**: Windows 11 Home
* **Primary Editor**: Visual Studio Code
* **Terminal Environment**: Git Bash / Windows Subsystem for Linux

## Core Project Modules

### 1. Log Monitoring System

The Log Monitoring System is an integrated toolset that bridges Bash and Python. It validates the system environment, provides interactive user prompts for report maintenance, and performs deep-text parsing of system logs to identify and report critical errors.

### 2. Project Backup Utility

The Project Backup Utility is a dedicated Bash script designed for local data redundancy. It allows for the recursive copying of multiple project directories into dated archives, ensuring that development progress is preserved locally before major updates or remote pushes.

## Technical Standards

Each project in this repository adheres to a strict set of professional development standards:

* **Modular Structure**: Logic is separated into specific folders for scripts, logs, and reports.
* **Documentation**: Every script includes a detailed header containing the date, author, and version history.
* **Error Handling**: Scripts are designed to validate the existence of files and directories before execution to prevent system failures.
* **Clarity**: All code and documentation utilize full words and avoid shorthand to ensure readability for collaborating developers.
