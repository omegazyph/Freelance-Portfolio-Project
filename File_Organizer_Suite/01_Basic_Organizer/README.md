# File Optimizer Suite by omegazyph

A collection of directory management tools designed to streamline workflows.

## Versions Included

1. **Basic (Bash):** Quick setup for basic file types.
2. **Standard (Bash):** Modular design using associative arrays for custom categories.
3. **Advanced (Python):** Robust error handling, logging, and duplicate file protection.

## Usage

- Ensure you have execute permissions: `chmod +x *.sh`
- Run the Python script: `python Advanced_Optimizer.py`
