## 📝 Description

The **Basic Tier** is a lightweight, "plug-and-play" solution for instant directory organization. It is designed for users who want a fast cleanup without the need for complex configurations or external folders.

This suite is fully compatible with **Windows 11** (optimized for Lenovo Legion systems) and Linux/Mac environments.

---

## ✨ Features

* **Zero Configuration:** Hardcoded categories for immediate use.
* **Dual-Language Support:** Includes both Python (.py) and Bash (.sh) versions.
* **Space-Safe:** Robust path handling for Windows usernames with spaces (e.g., "Wayne Stock").
* **Lightweight:** No external dependencies or configuration files required.
* **Branded Interface:** Signature omegazyph color-coded terminal output.

---

## 🚀 How to Use

### 1. Python Version (Windows/Mac/Linux)

Recommended for users with Python installed.

* Open your terminal (or VSCode).
* Run: `python Basic_Optimizer.py`

### 2. Bash Version (Linux/Git Bash)

Recommended for Git Bash users on Windows or native Linux users.

* Open Git Bash.
* Run: `bash Basic_Optimizer.sh`
